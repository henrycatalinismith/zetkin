Interface RemoteList<DataType>

Zetkin's front end uses the RemoteList interface to represent a reference to a collection in the back end. It's comparable to React Query's QueryResult object.

In addition to the collection itself, it contains metadata about the state of the collection, which is used to power things like loading states.

interface RemoteList<DataType> {
    error: unknown;
    isLoading: boolean;
    isStale: boolean;
    loaded: null | string;
    items: RemoteItem<DataType>[];
}

Type Parameters

  • DataType

    What type of remote list to represent. For example, if a remote item is defined with type RemoteList<User>, the data field will be of type User[].
